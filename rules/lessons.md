The same correction twice is a pattern. First look for a check that would catch
it — a test, a script, a lint rule, a hook. Write a rule only when nothing can
check it.

A rule that earns its place states one condition, one outcome, and when it does
not apply. Keep it to a line or two.

Drop a rule when a check covers it, or when it stopped being true.
